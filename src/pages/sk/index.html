FAQ

Praktické otázky

Je SIGEL iba SEO alebo technický audit? +

Nie. SEO, rýchlosť a technika sú iba jedna časť. SIGEL funguje ako business intelligence pre web: prepojí namerané dáta s UX, prístupnosťou, jasnosťou ponuky, dôverou, archetypmi a prioritnou roadmapou. Výsledkom nie je ďalší zoznam chýb, ale podklad pre rozhodnutie, čo riešiť ako prvé.

Je analýza automatická alebo ručne kontrolovaná? +

Základ vzniká nad analytickým systémom: zber signálov, technické kontroly, vlastný scoring, UX heuristiky a interpretačná vrstva. Každý report pred odoslaním prechádza ručnou kontrolou, aby mal jasné priority a dával praktický zmysel.

Koľko report stojí a pre koho je? +

Web Intelligence report stojí 199 € za jednu URL. Služba je určená firmám a podnikateľom, objednávka prebieha na faktúru. V cene je kompletný rozsah: merané technické a UX signály, komunikácia ponuky, archetypový playbook, prioritná roadmapa, evidence dáta a osobná kontrola každého reportu.

Kedy dáva Web Intelligence najväčší zmysel? +

Najväčší zmysel má pred investíciou do reklamy, pred redizajnom, pri slabých dopytoch z webu alebo vo chvíli, keď máte pocit, že ponuka je dobrá, ale ľudia jej nerozumejú. SIGEL nepridáva ďalšiu marketingovú vrstvu naslepo, ale najprv ukáže, kde môže web strácať výkon, dôveru alebo jasnosť.

Čo ak má web dobré technické skóre, ale obchodne nefunguje? +

Práve tam dáva SIGEL najväčší zmysel. Technický stav je iba jedna vrstva. Web môže byť rýchly, indexovateľný a formálne v poriadku, ale stále nemusí jasne vysvetľovať ponuku, budovať dôveru, viesť návštevníka k akcii alebo hovoriť k správnemu typu zákazníka.

Čo znamenajú archetypy značky a zákaznícke archetypy? +

Archetyp značky opisuje, ako firma na webe pôsobí: či komunikuje ako expert, tvorca, sprievodca, inovátor alebo iný typ značky. Zákaznícke archetypy pomáhajú určiť, aké motivácie, obavy a dôkazy potrebujú rôzne typy návštevníkov, aby ponuke porozumeli a mohli jej dôverovať.

Je výstup použiteľný aj pre agentúry? +

Áno. Agentúra môže report použiť ako vstupnú diagnostiku pred konzultáciou, redizajnom, SEO úpravami alebo obsahovou stratégiou. Podľa dohody môže slúžiť ako interný podklad, klientsky analytický vstup alebo základ vlastného odporúčania.

Čo výstup negarantuje? +

Report negarantuje zvýšenie tržieb, lepšie pozície vo vyhľadávaní ani výsledky reklamných kampaní. Je to diagnostický podklad pre rozhodnutie: ukazuje riziká, bariéry a priority, ktoré má zmysel riešiť skôr, než do webu, reklamy alebo redizajnu pošlete ďalší rozpočet.
